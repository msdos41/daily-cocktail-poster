# Daily Cocktail Poster

A bilingual, poster-first static web experience delivering one cocktail recommendation each day alongside a full gallery of drinks.

## Language

### Editorial & Product

**Daily Pour**:
The featured cocktail designated for a given calendar day.
_Avoid_: Daily pick, scheduled cocktail, today's cocktail

**Surprise Me**:
The interactive on-demand shuffle action that switches the current view to an alternate random cocktail.
_Avoid_: Reroll, randomizer, lucky pick

**The Collection**:
The comprehensive gallery page presenting all cocktails in the library.
_Avoid_: Archive, Past Picks, catalog, cocktail list

**Midnight Pour**:
The brand personality evoking an intimate night bar under low, atmospheric bar light.
_Avoid_: Dark mode, night theme, speakeasy theme

### Cocktail Structure

**Cocktail**:
A distinct beverage entry defined by its visual poster, recipe ratios, and tasting attributes.
_Avoid_: Drink, item, post

**Base Spirit**:
The primary alcoholic foundation (such as Gin, Whiskey, Rum, Tequila, Mezcal, or Vodka) categorizing a cocktail.
_Avoid_: Liquor, alcohol type, main ingredient

**Hero Ingredients**:
The signature 2 to 3 components highlighted directly on the visual poster.
_Avoid_: Key ingredients, main ingredients, highlights
